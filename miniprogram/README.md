# 邻里照护微信小程序演示版

原生微信小程序项目，使用 WXML、WXSS 和 JavaScript，无第三方依赖。

## 导入与运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择当前 `miniprogram` 文件夹。
3. AppID 使用游客模式或替换为自己的测试 AppID。
4. 编译后从首页进入；底部“需求进度”可切换家属、服务方、平台运营角色。

## 演示流程

首页或服务详情 → 发布演示需求 → 服务方响应 → 家属选择并确认服务单 → 服务方确认预约 → 开始服务 → 提交完成 → 家属确认并评价。

同时支持预约前取消、预约后双方确认取消/改期、投诉、平台提出处理结果、用户确认或申请复核。个人中心提供服务方入驻与模拟审核流程。

所有流程数据保存在当前微信开发者工具本地 Storage，只用于演示；页面不调用网络请求，不处理真实预约、支付、短信、地图、登录或资质文件。个人中心可重置演示数据，并可开启大字模式。

## 目录

- `domain/flow-machine.js`：纯业务状态机与角色权限校验。
- `services/api.js`：应用调用的 API 适配入口。
- `services/mock-adapter.js`：本地 Mock 实现；未来可新增 HTTP Adapter 替换。
- `pages/`：首页、需求发布、需求进度、服务方详情、投诉、服务方入驻及个人中心。
- `tests/flow-machine.test.js`：状态机行为测试。

## 验证

在项目目录运行：

```powershell
node --test tests/flow-machine.test.js
```

真实后端端点建议见上级目录 `API-CONTRACT.md`。上线前还需完成真实服务方审核、权限、隐私、备案和服务责任规则设计。
